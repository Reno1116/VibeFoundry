## 基本信息

- 工具名称：desktop-task-bubble
- 一句话说明：桌面常驻待办气泡，按优先级和截止时间颜色区分，支持倒计时追踪

## 需求

- 使用者：个人（开发者本人）
- 当前问题：缺乏一个可视化的桌面工具来实时跟进待办事项，无法直观看到"现在该做什么、还剩多少时间"
- 期望结果：桌面右侧常驻气泡列表，全局快捷键快速添加，颜色一眼区分优先级和截止紧迫度，可计时追踪，完成有历史存档
- 成功标准：
  - 全局快捷键 → 弹窗输入 → 桌面气泡立即出现
  - 从气泡颜色能一眼判断优先级和是否临近截止
  - 倒计时功能可用，到时 Windows 原生通知
  - 重启电脑数据不丢失
  - 日常使用不干扰其他工作（可隐藏、不抢焦点）

## 本次范围

### 要做

**输入与创建：**
- 全局快捷键（默认 `Ctrl+Shift+N`）呼出添加待办窗口
- 输入：任务标题（限 30 字）、优先级（高/中/低）、预计耗时（预设 15/30/60/120 分钟 + 手动输入）、截止时间
- 截止时间为可选字段；不填则气泡显示蓝色

**气泡展示：**
- 桌面右侧纵向排列，始终置顶（Topmost）
- 每个气泡显示：任务标题（超 30 字截断 + 省略号）、优先级色标、倒计时
- 优先级颜色：高 = 红色，中 = 橙色，低 = 绿色
- 截止时间用颜色深浅表示紧迫度：越临近截止颜色越深，已超时气泡变深红色
- 无截止时间 = 温和的蓝色，无紧迫度变化
- 深色模式跟随 Windows 系统主题自动切换

**排序规则：**
- 截止时间优先（临近截止排上面），同截止时间段内按优先级（高 > 中 > 低）
- 无截止时间的任务排在有截止时间的后面
- 排序自动刷新，不需要手动拖拽

**气泡操作：**
- 左键点击气泡 → 弹出操作菜单（完成 / 编辑 / 删除）
- 编辑：可修改全部字段（标题、优先级、预计耗时、截止时间）
- 删除：直接删除，不弹确认
- 完成：气泡消失，任务移入历史记录

**计时功能：**
- 点击气泡菜单中的"开始计时" → 倒计时开始
- 可暂停 / 继续 / 重置计时
- 倒计时结束 → Windows 原生通知提醒
- 关闭应用时计时暂停，重启后可继续

**数据与持久化：**
- 本地 JSON 文件自动保存（`%APPDATA%/desktop-task-bubble/tasks.json`）
- 重启电脑数据不丢失，计时进度保留
- 历史记录面板：查看已完成任务（标题、完成时间、实际耗时）

**系统集成：**
- 系统托盘图标常驻，右键菜单：显示/隐藏气泡、历史记录、设置、退出
- 多显示器支持：设置中选择固定显示屏幕
- 空状态：侧边栏显示引导文字"暂无待办，按 Ctrl+Shift+N 添加"

## 核心流程

1. **添加待办**：用户按 `Ctrl+Shift+N` → 弹出输入窗口 → 填写标题（必填）、优先级（默认中）、预计耗时、截止时间（可选）→ 点击确认 → 气泡出现在桌面右侧
2. **查看与管理**：气泡始终置顶显示 → 颜色一眼看出优先级和紧迫度 → 左键点击弹出菜单（开始计时 / 编辑 / 完成 / 删除）
3. **计时追踪**：点击开始计时 → 气泡显示倒计时 → 结束时 Windows 通知 → 气泡上可暂停或重置
4. **完成任务**：点击完成 → 气泡消失 → 任务移入历史记录 → 可在托盘菜单中查看历史
5. **隐藏与恢复**：托盘右键"隐藏气泡"→ 全部气泡消失，计时继续 → 托盘右键"显示气泡"→ 恢复
